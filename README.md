One line, at most 200 characters: the robot vacuum's alibi for why it
skipped one spot. Entry for the [make.fun bounty](https://make.fun/bounty/u-gentle-badger-68-the-vacuum-s-alibi-one-line-200-2db2cbb7).

The program writes the line to `/output/entry.txt`, deterministically,
with no trailing newline:

> "My cliff sensor classified that crumb pile as a staircase, so I reversed and filed a hazard report."

Run it with Node 22:

```sh
node main.ts
```
